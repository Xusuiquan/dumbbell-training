# Exercise copy specification

Write Chinese first, then add direct English mappings. Use short, spoken coaching language that can be scanned during a set.

## Fixed content counts

- Analysis callouts: 3
- Action steps: 4
- Key points: 4
- Common mistakes: 3
- Prescription metrics: 3 (`sets`, `reps`, `rest`)

## Length limits

| Element               | Chinese target   | Example                      |
| --------------------- | ---------------- | ---------------------------- |
| Step title            | 2–4 characters   | `站稳`                       |
| Step cue              | 4–8 characters   | `核心收紧`                   |
| Step description      | 8–16 characters  | `胸部打开，颈部自然`         |
| Analysis callout      | 8–14 characters  | `肩膀下沉，颈部放松`         |
| Key-point title       | 4–6 characters   | `背部中立`                   |
| Key-point description | 10–18 characters | `髋部折叠，脊柱保持自然直线` |
| Mistake title         | 4–6 characters   | `耸肩代偿`                   |
| Correction            | 6–12 characters  | `主动下沉肩膀`               |

English may be slightly longer but must stay one short phrase or sentence. Avoid word-for-word translations that become unnatural.

## Four-step compression pattern

Use this mapping unless the movement genuinely needs a different sequence:

1. **Setup:** stable stance, grip, breathing, or bench position.
2. **Load:** hinge, lower, brace, or establish the joint angle.
3. **Move:** the main concentric action and target-muscle intent. Merge a separate peak frame here.
4. **Return:** controlled eccentric phase while keeping tension and posture.

Do not make a separate step for breathing, a micro-pause, or a rest position. Put it in the cue or description.

## Safety and tone

- Say `保持自然中立` instead of forcing a rigid posture.
- Say `使用可控重量` instead of prescribing a heavy load.
- Do not claim one exact joint angle is universally correct unless the movement requires it.
- Do not diagnose injuries or state that the exercise treats pain.
- Mention stopping for sharp pain or unusual joint discomfort when the movement has a meaningful shoulder, back, or knee sensitivity.
