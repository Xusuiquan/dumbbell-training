# 哑铃动作记录：飞鸟与划船

> 当前只记录两个动作：哑铃飞鸟与单臂哑铃划船。两者的应用数据由 `src/data/exercises/dumbbell.ts` 维护，页面统一经 `src/data/exerciseCatalog.ts` 读取；后续增加动作时按相同结构新增即可。

## 使用边界

- 本文用于一般力量与动作学习，不把单一动作当作“矫正体态”或治疗骨盆前倾的方法。
- 对过度骨盆前倾的非手术干预，目前没有可靠证据证明可以稳定降低骨盆倾斜角度；更合适的目标是提升力量、躯干控制和活动耐受度。[系统综述](https://pubmed.ncbi.nlm.nih.gov/32071772/)
- 动作中若出现放射痛、麻木、明显无力，或腰髋疼痛加重，请停止并咨询医生或物理治疗师。

## 1. 哑铃飞鸟

**定位**：胸部辅助动作，重点练习胸大肌在可控范围内的收缩。全程在地面完成，只需一对哑铃。

**建议量**：2–3 组 × 10–15 次，休息 60–90 秒。选择能让上臂轻触地面后仍可稳定收回的轻重量。

**做法**：

1. 仰卧地面，双膝屈曲、双脚踩稳，双手将哑铃举于胸部上方。
2. 手肘全程微屈；吸气，沿弧线向两侧缓慢打开手臂。
3. 下放到上臂轻触地面或肩部仍舒适的位置即可。
4. 呼气，像拥抱大树一样沿弧线收回哑铃；不需要在顶端撞击哑铃。

**要点**：肩膀远离耳朵；下放慢于回收；宁可缩小幅度，也不要为了“拉得更开”让肩前侧不适。

**常见错误**：手肘锁死、让哑铃撞击地面、重量过大、回收时撞击哑铃。

## 2. 单臂哑铃划船

**定位**：背部拉力与肩胛控制动作。无需训练凳，可用空手轻扶同侧大腿以帮助保持躯干稳定。

**建议量**：2–3 组 × 8–12 次/侧，休息 60–90 秒。

**做法**：

1. 双脚与髋同宽，髋向后移、上身前倾；空手轻扶同侧大腿。
2. 持铃手自然下垂，先让肩膀远离耳朵，保持躯干稳定。
3. 将哑铃拉向髋部，感受肩胛骨向后下方移动；不要把身体跟着哑铃转动。
4. 顶点短暂停顿，再慢慢下放，完成一侧后换边。

**要点**：先稳定躯干再拉肘；哑铃朝髋部移动而不是胸口；始终自然呼吸。

**常见错误**：用下背甩动、耸肩、身体旋转、下放过快。

## 最小训练组合

每周 2 次即可起步；先做划船，再做飞鸟。每个动作 2 组，动作间休息 60–90 秒。能稳定完成全部建议次数且姿势不变形时，再小幅增加重量或次数。抗阻训练应以能持续执行和逐步进阶为核心。[ACSM 立场文件](https://pubmed.ncbi.nlm.nih.gov/39721287/)
